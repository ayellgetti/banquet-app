# Banquet Web

Frontend for Banquet CRM (enquiry, menu selection, procurement).

Part of the [banquet monorepo](../README.md). Prefer running from the repo root:

```sh
pnpm install
pnpm dev:web
```

Or from this directory:

```sh
pnpm install
pnpm dev
```

Theme docs: [docs/THEME.md](./docs/THEME.md).
